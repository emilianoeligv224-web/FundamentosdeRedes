# 5 Pilares de una Red Computacional

### INFRAESTRUCTURA FÍSICA Y CONEXIÓN

## NODOS:

### El Origen y Destino

Dispositivos que envían y reciben datos dentro del ecosistema de la red.

## ENLACES:

### El Camino Físico

Medios físicos o inalámbricos que establecen la conexión entre los diferentes nodos.


### LÓGICA Y REGLAS DE COMUNICACIÓN

Una red computacional es un sistema complejo de intercambio de información, requiriendo una combinación de infraestructura física y reglas lógicas para una comunicación efectiva.

## DIRECCIONES:

### Identidad Digital

Identificadores IP y MAC únicos que permiten localizar dispositivos de origen y destino:

## PROTOCOLOS:

### El Lenguaje Común

Reglas estrictas de formato y sintaxis que rigen la comunicación entre dispositivos.

## ENRUTAMIENTO:

### Gestión de Rutas

Proceso de decisión para determinar el camino mas eficiente para los datos.

### Actividad 1.4
la red debe cumplir con cuatro caracteristicas que se deben cumplir para enviar diferentes datos 
.Tolerancia a fallas
.Escalabilidad
.Calidad de servicio
.Seguridad

La calidad de servicio o QoS, es el conjunto de mecanismos que decide que trafico se atiende primero cuando la red no tiene capaidad suficiente para todo el tiempo 

Seguridad se refiere a proteger la red y la informacion que circula por ella contra accesos, modificaciones o interrupciones no autorizadas

.Suplantaciones de MAC/IP
.Ataques de intermediario 
.Denegación de servicio 
.Accesos no autorizados a un punto de acceso inalámbrico 

### Actividad 1.5
Una arquitectura de red es el conjunto de reglas y decisiones de diseño que definen como se organiza una red para que la comunicacion funcione: que funcion cumple cada parte.

Una red se divide dividiendola en capas independientes, donde cada capa resuelve un problema especifico sin necesitar saber como trabajar 
Modelo de referencia de siete capas fisicas, enlaces, red, transporte, sesion, presentacion y aplicacion, que describe, de forma teorica, todad las funciones que interviene en una comunicacion de red

### Modelo OSI
Capas:
1 -fisica
2 -data link
3 -network
4 -transport
5 -session
6 -presentation 
7-aplicacion


### Modelo tcp/ip
 1-aplicacion
 2- transporte
 3-internet
 4-acceso a red


### Encapsulamiento

Al bajar por las capas, cada una envuelve el dato con su propio encabezado; al llegar al destino, el proceso se invierte y cada capa retira el encabezado que le corresponde.
